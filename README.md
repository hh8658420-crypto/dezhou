# 巅峰德州 · 手机直接玩联机版 V1.1

这是一个可部署到公网、让 iPhone / Android / 电脑直接打开网址游玩的 2–6 人好友房德州扑克项目。服务器统一维护洗牌、手牌、下注顺序、倒计时和结算，浏览器只负责显示及发送操作。

> 仅使用虚拟娱乐筹码，不包含充值、提现或现金交易。

## 本版新增的手机功能

- 公网部署后，手机只需打开网址，无需安装 Node.js
- 房主点击“邀请好友”，可直接分享带房间号的加入链接
- iPhone / Android 可添加到主屏幕，以接近 App 的全屏方式打开
- 操作按钮固定在手机底部，支持刘海屏和底部安全区
- 手机竖屏、横屏和电脑页面自适应
- WebSocket 断线自动重连

## 已实现的游戏功能

- 创建房间、6 位房间号加入、等待房间列表
- 2–6 人牌桌与虚拟娱乐筹码
- 服务器端安全随机洗牌、每人两张私有手牌
- 庄家、小盲、大盲轮转
- 翻牌前、翻牌、转牌、河牌、摊牌完整流程
- 弃牌、过牌、跟注、加注、全下
- 25 秒行动倒计时与超时自动过牌/弃牌
- 完整牌型判断、主池和边池分配、平局分池
- 同一浏览器凭令牌断线重连

## 最简单的手机上线方式：Render

项目根目录已包含 `render.yaml`，配置了 Node.js、WebSocket、健康检查及新加坡节点。

1. 把解压后的所有文件上传到一个 GitHub 仓库根目录，不要只上传 `public` 文件夹。
2. 登录 Render，选择 **New → Blueprint**。
3. 连接刚才的 GitHub 仓库。
4. Render 会自动读取 `render.yaml`，确认创建服务。
5. 部署成功后会得到一个 `https://...onrender.com` 公网地址。
6. 用手机打开该地址，创建房间，再点“邀请好友”分享链接。

不要把本项目部署到 GitHub Pages。GitHub Pages 只能托管静态网页，无法运行 Node.js 和 Socket.IO 联机服务器。

### 免费服务器说明

`render.yaml` 默认使用免费实例，适合测试和好友娱乐。免费实例长时间没有访问会休眠，服务器重启或休眠后，保存在内存中的房间会清空。正式长期运行时，把 Render 实例升级为付费常驻实例，并进一步接入数据库或共享状态服务。

## 安装到手机桌面

### iPhone

用 Safari 打开游戏网址，点击浏览器的“分享”按钮，再选择“添加到主屏幕”。

### Android

用 Chrome 打开游戏网址，点击页面中的“安装到手机桌面”，或在浏览器菜单选择“安装应用”。

## 本地运行

需要 Node.js 18 或更高版本：

```bash
npm install
npm start
```

打开：

```text
http://localhost:3000
```

## 自动测试

```bash
npm test
```

当前包含 6 项测试：牌型、边池、弃牌结算、筹码守恒，以及两个真实 Socket.IO 客户端创建、加入并同步开局。

## 项目结构

```text
render.yaml                  Render 一键部署配置
Dockerfile                   通用容器部署配置
server.js                    Express / Socket.IO 服务端
src/game-room.js             牌局状态机、下注流程、倒计时
src/poker.js                 洗牌、牌型比较、主池和边池结算
public/index.html            手机和电脑游戏页面
public/styles.css            响应式牌桌及触控样式
public/app.js                联机、邀请、安装和界面逻辑
public/manifest.webmanifest  手机桌面应用配置
public/sw.js                 PWA 静态资源缓存
public/icons/                手机桌面图标
```

## 当前边界

- 房间状态保存在单台服务器内存中，服务器重启后房间清空。
- 当前没有账号、充值、提现、现金结算和永久战绩。
- 适合好友房 MVP；后续商业化需要账号系统、数据库、风控、日志审计和多实例共享状态。
