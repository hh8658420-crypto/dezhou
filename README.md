# 巅峰德州 · 多人联机版

一个可直接运行的 2–6 人好友房德州扑克 MVP。所有关键状态由 Node.js 服务器统一维护，前端通过 Socket.IO 实时同步。

## 已实现

- 创建房间、6 位房间号加入、等待房间列表
- 2–6 人牌桌与虚拟娱乐筹码
- 服务器端安全随机洗牌、每人两张私有手牌
- 庄家、小盲、大盲轮转
- 翻牌前、翻牌、转牌、河牌、摊牌完整流程
- 弃牌、过牌、跟注、加注、全下
- 25 秒行动倒计时与超时自动过牌/弃牌
- 10 种牌型判断（含皇家同花顺归入同花顺）
- 主池与边池分配、平局分池
- 手机/电脑响应式页面
- 同一浏览器凭令牌断线重连

## 本地启动

需要 Node.js 18 或更高版本。

```bash
npm install
npm start
```

浏览器打开：

```text
http://localhost:3000
```

联机测试：在电脑打开一个窗口，再用手机访问电脑的局域网地址，例如：

```text
http://192.168.1.20:3000
```

电脑和手机必须连接同一个 Wi-Fi，并允许系统防火墙放行 Node.js。

## 部署说明

这是 Node.js + WebSocket 项目，不能只使用 GitHub Pages（GitHub Pages 只能托管静态网页，不能运行此服务器）。可部署到支持常驻 Node.js/WebSocket 的服务，然后把启动命令设置为 `npm start`。

常用环境变量：

```text
PORT=3000
```

健康检查地址：`/health`

## 项目结构

```text
server.js              Socket.IO 服务器、房间与连接管理
src/game-room.js       牌局状态机、下注流程、倒计时
src/poker.js           洗牌、牌型比较、主池/边池结算
public/index.html      游戏页面
public/styles.css      桌面与手机样式
public/app.js          浏览器联机与界面逻辑
test/poker.test.js     牌型和边池测试
```

## 当前版本边界

- 数据保存在服务器内存中，服务器重启后房间清空。
- 目前是好友房娱乐筹码，没有账号、充值、提现或现金功能。
- 单服务器进程适合 MVP。多实例横向扩容时需要共享房间状态及 Socket.IO Adapter。
